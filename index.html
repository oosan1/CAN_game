📖 CAN 2.0A 標準データフレーム仕様（プレイ中も参照できます）

1. バスレベルと調停 (Arbitration)

  • 0 = ドミナント (Dominant / 優勢)、1 = リセッシブ (Recessive / 劣勢)。
  • 複数ノードが同時送信すると Wired-AND（1つでも 0 ならバスは 0）。
  • 自分が 1 を出したのにバスが 0 なら調停負け！即座に送信停止（Back Off）して相手の EOF + IFS 完了を待ちます。

2. ビットスタッフィング & CRC-15

  • スタッフ範囲：SOF 〜 CRC (15bit) まで。（CRC Delim 以降はなし）
  • 同じビットが 5連続（00000 / 11111）したら、直後に 反転ビット（スタッフビット）を1つ挿入（挿入ビットもカウント対象）。
  • CRC-15多項式：1100010110011001（16bit）。SOF〜Data（デスタッフ済35bit）の末尾に 0 を15個足してXOR除算した15bitの余り。
